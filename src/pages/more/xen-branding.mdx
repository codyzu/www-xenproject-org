      <h2>Usage</h2>
      <p>Xen mascots, templates and other images available through this page and are made available under CC BY-NC 3.0. Feel free to use images on your blog, as wallpaper, for fun and the like, but you must link to xenproject.org.</p>
      <p>Creative Commons CC BY-NC 3.0 allows you to:</p>
      <ul>
        <li>Share: copy, distribute, and transmit the material</li>
        <li>Remix: create derivative works of the material</li>
      </ul>
      <p>Under these conditions:</p>
      <h3>Attribution</h3>
      <p>You can use the images and material without attribution when used in a context that refers to the Xen Project, Xen Project Hypervisor, Xen Project Community, XenProject Sub-Projects, or XenProject.org (e.g. in a blog post or article about the Xen Project, a Xen Project Hackathon, a Xen Project User Group meeting, etc.). Where the context is not clear, attribution must be made to XenProject.org, and images used on merchandise, such as a sticker, must contain the Xen Project logo.</p>
    </div>

    <div class="vertical-lists">
      <div class="list-column">
        <h2>Examples of clear context</h2>
        <ul>
          <li>A training course entitled "How to use the Xen Project Hypervisor to build a cloud"</li>
          <li>A website "xen_project_hall_of_fame.com" with pictures of famous Xen Project contributors</li>
          <li>A monthly journal called "Xen Project User journals" describing how you use the Xen Project Hypervisor</li>
          <li>A blog post or article about the Xen Project Hypervisor</li>
          <li>As avatar for a social media account with a reference to Xen Project in the profile name or in the profile description</li>
          <li>Give-away of a Xen Fu Panda button, sticker, mug, etc. at a Xen Project user group meeting or Hackathon</li>
        </ul>
      </div>
      <div class="list-column">
        <h2>Examples of unclear context</h2>
        <ul>
          <li>A freely distributed Xen Project wallpaper or theme</li>
          <li>Give-away of a Xen Fu Panda button, sticker, mug, etc. at a kids event</li>
        </ul>
      </div>
    </div>
  </div>
