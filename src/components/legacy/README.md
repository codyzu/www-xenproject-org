# Legacy Components

Migrated compatibility components live here. They preserve existing pages and may depend on the legacy Sass cascade from `LegacyLayout.astro`.

Do not add new redesign components here. Limit changes to compatibility fixes, migration maintenance, and bug fixes for existing public pages.

Legacy pages and the Ghost fragment still depend on this directory. Follow
[`docs/design-system.md`](../../../docs/design-system.md) when migrating a route
to the Astro-first foundation.
