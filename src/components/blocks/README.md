# Blocks

Reusable composed page sections live here: heroes, CTAs, feature grids, logo
clouds, stats, and callouts.

Blocks compose primitives and stay independent of the legacy Sass cascade.
Add one only after multiple real pages establish a stable contract, and
demonstrate reusable additions on `/internal/design-system/`. See
[`docs/design-system.md`](../../../docs/design-system.md).
