## Tutorial

- Go to folder `static/img`
- Go to a subfolder of `static/img` according to the type of the image (for example `static/img/figures`)

![Go to the folder](images/gitlab/add-image-folder.png)


- Clic on the button ` +`

![button upload file](images/gitlab/add-image-upload-file.png)

- Choose `Upload file`

- Clic on upload or drag and drop your image
![alt text](images/gitlab/add-image-upload-dialog.png)
![alt text](images/gitlab/upload-view.png)


- Clic on the button `Commit changes`
![alt text](images/gitlab/add-image-commit-changes.png)

- Return to the `content` folder for the pages
- Edit the page and add the image in the page

![alt text](images/gitlab/add-image-in-page.png)

- Clic on the button `Commit changes`
- And clic again on `Commit changes`
