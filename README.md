## Run the project on your computer

Git clone the project on your computer (check how to on the main page of the project)


Install Hugo :

[https://gohugo.io/installation/](https://gohugo.io/installation/)

Run Hugo : 

```bash
hugo server -D --logLevel debug --config hugo.yaml,hugo.dev.yaml
```

Open the website on http://localhost:1313
